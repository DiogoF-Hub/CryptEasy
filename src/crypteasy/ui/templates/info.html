Comment ça marche

Deux clés par personne

Chaque utilisateur possède une paire de clés :

  • la clé publique se partage librement : elle sert à vous chiffrer des fichiers ;
  • la clé privée reste sur votre ordinateur, protégée par votre mot de passe : elle seule permet de déchiffrer.

Vous pouvez avoir plusieurs paires (une par PC, une perso, une pour le travail…).

Chiffrement hybride

  1. 1Une clé aléatoire de 32 octets est tirée, une par fichier.
  2. 2Elle est « enveloppée » avec la clé publique du destinataire (RSA-OAEP, ou X25519 + HKDF).
  3. 3Le fichier est chiffré en AES-GCM par blocs de 64 Kio : chaque bloc est aussi protégé contre la modification.
  4. 4Pour ouvrir, la clé privée du destinataire désenveloppe la clé du fichier.

Pourquoi deux étapes ? Le chiffrement à clé publique est lent et limité en taille ; AES est rapide sur de gros fichiers. On combine les deux.

Pourquoi le sel compte

Sans sel, le même mot de passe donne toujours la même clé. Un attaquant peut alors précalculer ses essais une seule fois (« tables arc-en-ciel ») et les réutiliser contre tous les fichiers.

Avec un sel aléatoire, chaque essai ne vaut que pour un seul fichier : il faut tout recommencer pour le suivant. L'option « aucun sel » existe pour la démonstration, notée 🔴.

Vérifier une empreinte

L'empreinte est un résumé unique de la clé publique (SHA-256), identique sur toutes les machines. Quand vous ajoutez un contact, comparez-la avec lui de vive voix.

Si quelqu'un a remplacé la clé pendant son envoi (mail, messagerie…), les empreintes ne correspondront pas : c'est le seul moyen de détecter cette attaque « de l'homme du milieu ».

Le paquet chiffré .zip

Format en cours de validation par l'équipe : les détails peuvent encore changer.

FichierContenuLisible sans la clé ?

Chaque bloc est authentifié avec le contenu exact de manifest.json : modifier un réglage ou un seul octet rend le paquet illisible, et rien n'est déchiffré.

Conseils

  • Sauvegardez votre clé privée (Mes clés → Exporter la clé privée) sur un support à vous : si vous la perdez, ou oubliez son mot de passe, les fichiers chiffrés pour vous sont perdus. Personne ne peut les récupérer.
  • N'envoyez jamais votre clé privée à quelqu'un.
  • Un mot de passe long (une phrase) vaut mieux qu'un mot de passe compliqué.
  • Transmettez un mot de passe de fichier par un autre canal que le paquet.

Ce que CryptEasy ne fait pas

  • envoyer les fichiers : c'est vous qui envoyez le paquet ;
  • protéger un ordinateur déjà infecté (un logiciel espion peut lire la clé pendant son utilisation) ;
  • cacher qu'un fichier a été échangé, ni sa taille approximative ;
  • ouvrir des fichiers chiffrés par d'autres outils (GPG, 7-Zip…).
